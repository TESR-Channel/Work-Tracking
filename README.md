# TESR Time Clock

ระบบลงเวลาเข้า–ออกงาน ใบลา และรายงานสิ้นเดือนของ TESR Co., Ltd.

| หน้า | ใช้โดย | อุปกรณ์ |
|---|---|---|
| `index.html` | พนักงาน: เช็คอิน/เช็คเอาท์ด้วย QR + GPS, ปฏิทินของฉัน, ยื่นใบลา, ขอแก้เวลา, โปรไฟล์ | มือถือ / iPad |
| `admin.html` | แอดมิน: ภาพรวมวันนี้, อนุมัติคำขอ, ปฏิทินทีม, รายงานรายเดือน, พนักงาน, วันหยุด, ตั้งค่า & QR | คอมพิวเตอร์ (ใช้บนมือถือได้) |

ข้อมูลทั้งหมดเก็บใน Google Sheet ผ่าน Google Apps Script

## การแยกสิทธิ์และความปลอดภัย
- **ล็อกอินแยกกัน:** พนักงานและแอดมินใช้หน้าล็อกอินคนละหน้า และใช้ token คนละแบบ server ตรวจสิทธิ์ทุกคำสั่ง บัญชีพนักงานจึงเรียกคำสั่งของแอดมินไม่ได้แม้จะเปิดหน้า `admin.html`
- **บัญชีพนักงาน:** พนักงานลงทะเบียนเองครั้งแรกด้วย **รหัสพนักงาน + เบอร์โทร** ที่แอดมินบันทึกไว้ แล้วตั้งชื่อผู้ใช้และรหัสผ่านเอง
- **การเก็บรหัสผ่าน:** เก็บแบบ hash (SHA-256 + salt) ไม่มีใครเห็นรหัสผ่านจริง รวมถึงแอดมิน ถ้าพนักงานลืมรหัส แอดมินกด "รีเซ็ตบัญชี" แล้วพนักงานลงทะเบียนใหม่
- **กันเดารหัส:** ใส่รหัสผิด 5 ครั้งจะล็อก 15 นาที
- **เวลาและพื้นที่:** ใช้เวลาของ server ทั้งหมด QR ใช้ได้เฉพาะวันนั้น และต้องอยู่ในรัศมีที่ตั้งไว้
- **หลักฐานการอนุมัติ:** ทุกใบลาและคำขอแก้เวลาเก็บไว้ในชีต `Leaves` / `Adjustments` พร้อมเวลาที่พิจารณาและหมายเหตุของแอดมิน

## ชีตใน Google Sheet
| ชีต | เก็บอะไร |
|---|---|
| `Employees` | รายชื่อพนักงาน, บัญชีเข้าระบบ (hash), เวลางานรายคน, สิทธิ์ลาต่อปี |
| `Records` | เวลาเข้า–ออก (1 แถว = 1 คน 1 วัน) |
| `Leaves` | ใบลา: ประเภท, ช่วงวันที่, เต็มวัน/ครึ่งวัน, เหตุผล, สถานะ |
| `Adjustments` | คำขอแก้เวลา และผลการพิจารณา |
| `Holidays` | วันหยุดบริษัท |
| `Settings` | ตั้งค่าระบบ |
| `สรุป yyyy-MM` | สรุปรายเดือนสำหรับทำเงินเดือน สร้างใหม่ทุกคืนเวลา 23:30 น. |

**กติกาการนับ**
- **มาสาย:** เช็คอินหลังเวลาเข้างานของคนนั้นบวกเวลาผ่อนผัน (ตั้งเวลางานรายคนได้ที่เมนูพนักงาน ถ้าเว้นว่างจะใช้เวลางานบริษัท)
- **ขาด:** วันทำงานที่ผ่านไปแล้วแต่ไม่มีเวลาเข้า และไม่มีใบลาที่อนุมัติ
- **ลาครึ่งวันเช้า:** ถ้าอนุมัติแล้ว วันนั้นไม่นับสาย
- **ลาครึ่งวันแต่ไม่มาเลย:** นับขาด 0.5 วัน
- **วันลา:** หักวันหยุดบริษัทและวันหยุดประจำสัปดาห์ให้อัตโนมัติ

## ติดตั้ง (ประมาณ 10 นาที)

### 1. Google Sheet + Apps Script
1. สร้าง Google Sheet ใหม่ ตั้งชื่อว่า `TESR Time Clock`
2. ไปที่ **Extensions → Apps Script** ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาของ `apps-script/Code.gs` ทั้งไฟล์
3. ไปที่ ⚙️ **Project Settings** ติ๊ก *Show "appsscript.json"* แล้ววางเนื้อหาจาก `apps-script/appsscript.json`
4. เลือกฟังก์ชัน `setup` แล้วกด **Run** และอนุญาตสิทธิ์ (Sheets, Drive, Triggers)

### 2. Deploy เป็น Web App
1. ไปที่ **Deploy → New deployment → Web app**
2. ตั้ง **Execute as: Me** และ **Who has access: Anyone** แล้วกด **Deploy**
3. คัดลอก URL ที่ลงท้ายด้วย `/exec`

> ทุกครั้งที่แก้ `Code.gs` ให้ไปที่ **Deploy → Manage deployments → ✏️ → Version: New version** เพื่อให้ URL เดิมใช้โค้ดใหม่

### 3. เชื่อมหน้าเว็บ
แก้ไฟล์ `assets/config.js` ใส่ URL ที่ได้จากขั้นตอนที่ 2:
```js
window.TESR_API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```
ถ้า `TESR_API_URL` ว่าง ระบบจะเป็นโหมดทดลองที่ใช้ข้อมูลสมมุติในเบราว์เซอร์

### 4. ตั้งค่าครั้งแรก (หน้า `admin.html`)
1. เข้าระบบด้วย `admin` / `tesr1234` แล้ว **เปลี่ยนรหัสผ่านทันที** ที่เมนู ตั้งค่า & QR Code
2. ตั้งพิกัดออฟฟิศ: ยืนอยู่ที่ออฟฟิศแล้วกด "ใช้ตำแหน่งที่ฉันยืนอยู่ตอนนี้"
3. ใส่ URL หน้าพนักงาน `https://tesr-channel.github.io/Work-Tracking/` เพื่อให้ QR สแกนด้วยกล้องมือถือปกติได้
4. ไปที่ **พนักงาน → นำเข้าจาก CSV** แล้วนำเข้ารายชื่อพนักงาน คอลัมน์ที่ใช้: `code,name,gender,email,phone,position,shiftStart,shiftEnd,qPersonal,qSick,qVacation,qMaternity`
5. ไปที่ **วันหยุดบริษัท** แล้วเพิ่มวันหยุดของปี

> ไฟล์รายชื่อพนักงานจริงห้ามใส่ไว้ใน repo นี้ เพราะ repo เป็น public ให้นำเข้าผ่านหน้าแอดมินเท่านั้น

### 5. แจ้งพนักงาน
เปิด `https://tesr-channel.github.io/Work-Tracking/` แล้วกด **ลงทะเบียนครั้งแรก** ใส่รหัสพนักงาน + เบอร์โทร แล้วตั้งชื่อผู้ใช้และรหัสผ่าน หลังจากนั้นใช้หน้าเดียวกันนี้ทุกวัน

## ลืมรหัสแอดมิน
เปิด Google Sheet แล้วไปที่เมนู **TESR Time Clock → รีเซ็ตรหัสผ่านแอดมินเป็นค่าเริ่มต้น** (ทำได้เฉพาะเจ้าของชีต)

## สำหรับนักพัฒนา
- **`assets/core.js`:** logic ทั้งหมด (สิทธิ์, ลา, สาย, รายงาน) ใช้ไฟล์เดียวกันทั้งใน Apps Script และโหมดทดลอง
- **`src/sheets-adapter.gs`:** ส่วนที่ต่อกับ Google Sheet
- **`./build.sh`:** รวมสองไฟล์ข้างบนเป็น `apps-script/Code.gs` ให้รันทุกครั้งหลังแก้ `core.js`
