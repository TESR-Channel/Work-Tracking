# TESR Time Clock

ระบบลงเวลาเข้า–ออกงานพนักงาน TESR
- หน้าเว็บ (`index.html`) อยู่บน GitHub Pages
- ข้อมูลเก็บใน Google Sheet ผ่าน Google Apps Script ไม่ต้องใช้ Supabase

## โครงสร้าง

```
index.html               หน้าเว็บ (พนักงาน + แอดมิน)
apps-script/Code.gs      หลังบ้าน วางใน Apps Script ของ Google Sheet
apps-script/appsscript.json
```

## ข้อมูลใน Google Sheet

| ชีต | เก็บอะไร |
|---|---|
| `Employees` | id, รหัส, ชื่อ, ตำแหน่ง, ลิงก์รูป, active |
| `Records` | 1 แถว = 1 คน 1 วัน: วันที่, เข้า, ออก, สาย(นาที), ระยะจากออฟฟิศ |
| `Settings` | พิกัดออฟฟิศ, รัศมี, เวลาเข้า–เลิกงาน, ผ่อนผัน, วันทำงาน, URL หน้าเว็บ, PIN แอดมิน |
| `Holidays` | วันหยุดบริษัท (yyyy-MM-dd, ชื่อวัน) ไม่นับเป็นวันขาด |
| `สรุป 2026-10` … | ชีตสรุปรายเดือน สร้างอัตโนมัติทุกคืน 23:30 น. |

ชีตสรุปแต่ละเดือนมี 2 ส่วน:
1. **สรุปรายคน:** วันทำงาน, มา, ขาด, มาสาย (วัน), สายรวม (นาที), ลืมเช็คเอาท์, ชั่วโมงทำงาน
2. **รายละเอียดรายวัน:** วันที่, ชื่อ, สถานะ (มา / สาย / ขาด), เวลาเข้า, เวลาออก, สายกี่นาที แถวที่ขาดเป็นสีแดง แถวที่สายเป็นสีส้ม

## ติดตั้ง (ประมาณ 10 นาที)

### 1. สร้าง Google Sheet + Apps Script
1. สร้าง Google Sheet ใหม่ ตั้งชื่อ `TESR Time Clock`
2. ไปที่เมนู **Extensions → Apps Script**
3. ลบโค้ดเดิม แล้ววางโค้ดจาก `apps-script/Code.gs`
4. กด ⚙️ **Project Settings** แล้วติ๊ก *Show "appsscript.json"* จากนั้นวางเนื้อหาจาก `apps-script/appsscript.json`
5. เลือกฟังก์ชัน `setup` แล้วกด **Run** และกดอนุญาตสิทธิ์ (Sheets, Drive, Triggers)
6. กลับไปที่ชีต `Settings` แล้วแก้ค่าต่อไปนี้:
   - **`adminPin`:** เปลี่ยนจาก 1234 เป็นรหัสของคุณเอง
   - **`lat` / `lng`:** พิกัดออฟฟิศจริง หรือจะตั้งทีหลังจากหน้าแอดมินด้วยปุ่ม "ใช้ตำแหน่งที่ฉันยืนอยู่ตอนนี้" ก็ได้

### 2. Deploy เป็น Web App
1. กด **Deploy → New deployment → Web app**
2. ตั้งค่า **Execute as:** Me และ **Who has access:** Anyone
3. กด **Deploy** แล้วคัดลอก URL ที่ลงท้ายด้วย `/exec`

> ทุกครั้งที่แก้ `Code.gs` ให้ไปที่ **Deploy → Manage deployments → ✏️ → Version: New version** เพื่อให้ URL เดิมใช้โค้ดใหม่

### 3. ใส่ URL ในหน้าเว็บ แล้วขึ้น GitHub Pages
1. เปิด `index.html` แล้วแก้บรรทัดนี้:
   ```js
   const API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
   ```
2. เปิด GitHub Pages ที่ **Settings → Pages → Source: Deploy from a branch → Branch: main / (root)**
3. หน้าเว็บจะอยู่ที่ **https://tesr-channel.github.io/Work-Tracking/**
4. เข้าโหมด **แอดมิน → ตั้งค่า** ใส่ URL ด้านบนในช่อง "URL หน้าเว็บนี้" แล้วกดบันทึก จากนั้น QR จะเป็นลิงก์ที่สแกนด้วยกล้องมือถือได้ทันที

### 4. เริ่มใช้
1. แอดมินเพิ่มพนักงานในแท็บ **พนักงาน**
2. แสดง QR ของวันในแท็บ **ตั้งค่า & QR Code** บนแท็บเล็ตหน้าออฟฟิศ หรือพิมพ์ทุกเช้า
3. พนักงานเลือกชื่อตัวเองครั้งแรก เครื่องจะจำไว้ จากนั้นสแกน QR แล้วกดยืนยัน

## การตรวจสอบฝั่ง server (ปลอมจากหน้าเว็บไม่ได้)
- **เวลา:** ใช้เวลาของ server ไม่ใช้เวลาของมือถือ
- **QR:** ใช้ได้เฉพาะวันนี้ รหัสสร้างจาก HMAC กับ secret ที่เก็บใน Script Properties
- **ระยะทาง:** คำนวณจากพิกัด GPS ของมือถือเทียบกับพิกัดออฟฟิศ ถ้าเกินรัศมีจะปฏิเสธ
- **การบันทึกพร้อมกัน:** ใช้ `LockService` ไม่ให้ข้อมูลชนกันเมื่อหลายคนสแกนพร้อมกัน
- **แอดมิน:** ทุกคำสั่งของแอดมินต้องใช้ PIN

## ข้อจำกัดที่ควรรู้
- **เลือกชื่อแทนคนอื่นได้:** คนที่อยู่ในออฟฟิศสามารถเลือกชื่อแล้วเช็คอินแทนเพื่อนได้ ถ้าต้องการกันตรงนี้ ให้เพิ่ม PIN ส่วนตัวของพนักงานได้ในเวอร์ชันถัดไป
- **ปลอม GPS ได้:** แอปปลอม GPS บน Android หลอกระยะได้ แต่ยังต้องได้ QR ของวันนั้นด้วย
- **รูปโปรไฟล์:** เก็บใน Google Drive โฟลเดอร์ `TESR Time Clock · Photos` และแชร์แบบ "ทุกคนที่มีลิงก์"
- **ความเร็ว:** Apps Script ตอบกลับประมาณ 1–3 วินาที เพียงพอสำหรับทีมไม่เกินประมาณ 30 คน
